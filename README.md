# 大数据学习平台

面向「大数据管理与应用」专业学生的个人学习平台：大三零基础 · 数据工程 + AI 数据方向 · 11 个月冲刺。

## 功能

- 📋 **仪表盘**：倒计时（实习投递/秋招）、任务完成率、已掌握数、连续学习天数、每日打卡
- 🗂️ **路线任务**：32 个任务按 S0-S3 四阶段组织，每个任务含知识点详解 + 零基础名词解释 + 自测题
- 📈 **技能进度**：21 项技能自评，每项含详解
- 🍅 **番茄钟**：25/5/15 分钟专注，累计时长
- 📝 **笔记日志**：学习笔记 + 每日日志 + 错题本
- 🔍 **全局搜索**：搜索任务、技能、名词、知识点
- 💾 **数据管理**：导出/导入备份，数据只存本地浏览器

## 使用说明

1. 直接用浏览器打开 [index.html](index.html)（或访问本 Pages 链接）
2. 所有学习数据（打卡、任务、笔记、错题）保存在**本地浏览器**中，不上传任何服务器
3. 换设备/清缓存前，务必使用页面底部「⬇ 导出备份」保存数据，再到新设备「⬆ 导入」
4. 单文件应用，可离线使用，无需安装任何软件

## 更新

内容更新时直接覆盖本仓库的 `index.html` 即可，Pages 链接不变。
